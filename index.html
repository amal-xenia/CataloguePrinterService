API Reference

Integrate your applications directly using these local REST endpoints.

GET /printers Fetch installed printers list

Returns an array of all installed system printers with connection statuses.

HTTP Response (200)
{
  "message": "Printers fetched successfully",
  "printers": [
    {
      "name": "POS-80C",
      "printerStatus": "Ready",
      "connectionStatus": "Connected",
      "isConnected": true
    }
  ]
}
POST /print Send print job

Send a base64 encoded PDF or image to be printed. Page width will scale automatically.

HTTP Request Payload
{
  "imageBase64": "data:image/png;base64,iVBORw...",
  "printernamefromfrontend": ["POS-80C"],
  "paperWidth": 80 // Optional: 58, 80, or 100
}
POST /clear-queue Clear print queue

Cancels all pending print operations for a printer.

HTTP Request Payload
{
  "printerName": "POS-80C"
}
POST /check-connection Verify printer connectivity

Verify if a specific system printer is online and ready.

HTTP Request Payload
{
  "printerName": "POS-80C"
}
HTTP Response (200)
{
  "message": "Connection check complete",
  "results": [
    {
      "name": "POS-80C",
      "status": "Ready",
      "workOffline": false,
      "connectionStatus": "Connected",
      "port": "USB001"
    }
  ]
}
POST /queue Inspect printer job queue

Get a list of all active pending print jobs for a specific printer.

HTTP Request Payload
{
  "printerName": "POS-80C"
}
HTTP Response (200)
{
  "message": "1 jobs pending",
  "jobs": [
    {
      "id": 152,
      "document": "KOT-Receipt-25949.pdf",
      "status": "Printing",
      "time": "6/19/2026 4:30:15 PM"
    }
  ]
}
